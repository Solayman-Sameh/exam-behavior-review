# Interface assets

exam_review.ico is the original navy shield-and-eye app icon, with sizes from 16 to 256 pixels and a transparent exterior. exam_review.png is its 256-pixel preview. Rebuild both with python scripts/build_app_icon.py; it uses the existing Pillow dependency and geometric drawing commands. Runtime screenshots belong in alerts/, not here.

demo.mp4 is the video demonstration of the Exam Behavior Review desktop application in action.
